# sougandhmp.github.io
Developer Profile, served at https://sougandh.dev by GitHub Pages from the `develop` branch.

Plain HTML, CSS and JavaScript with no build step: open `index.html` in a browser to preview.

| File | What's in it |
|---|---|
| `index.html` | Page content: hero, experience, skills, projects, recommendations, about |
| `css/styles.css` | All styles, including light/dark theme colours at the top |
| `js/main.js` | Theme toggle, nav, job "Show more", project filters, résumé viewer |
| `js/floaters.js` | The floating tech icons in the page margins (one entry per icon) |
| `cover.html` | Animated cover banner, embedded in the page |
| `cover.png`, `og-image.png` | Static renders of the cover, used for link previews |
